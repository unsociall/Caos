# CAOS

Projeto experimental de inteligência artificial pessoal. A publicação do código e relatórios será feita após revisão de segurança e verificação de licenças.

Memória persistente, agentes especializados, conselho cognitivo, autonomia supervisionada, aprendizado progressivo e execução em Android/Termux, PC e servidor.
